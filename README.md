# 🛡️ Cyber Security Dashboard Portal

## 📌 Project Overview

Cyber Security Dashboard Portal is a web-based project developed using HTML, CSS, and JavaScript.

The project simulates a secure login system and displays a cyber security dashboard containing security-related information and monitoring cards.

---

## 🚀 Features

- Secure Login Interface
- Password Validation
- Show/Hide Password Feature
- Responsive Dashboard Design
- Security Status Card
- Firewall Status
- Network Monitoring
- Phishing Alert Information
- Modern User Interface

---

## 🛠 Technologies Used

- HTML
- CSS
- JavaScript

---

## 🔐 Project Workflow

1. User enters username and password.
2. Password is validated based on security rules.
3. Successful login redirects to the dashboard.
4. Dashboard displays cyber security information and monitoring cards.

---

## 🎯 Purpose

The purpose of this project is to understand the fundamentals of login validation, dashboard design, and basic cyber security concepts using front-end technologies.

---

## 📚 Concepts Used

- Authentication Basics
- Password Validation
- User Interface Design
- Cyber Security Awareness
- JavaScript DOM Manipulation
